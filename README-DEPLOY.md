# ParcelProof — Website #23

A complete static website for GitHub and Vercel.

## Deployment
1. Extract this ZIP into the root of a new GitHub repo (index.html must be in root).
2. Import it in Vercel as an Other/static site; no build command or framework needed.
3. Assign the URL `https://parcelproof.vercel.app` if available. The name is provisional: replace this URL everywhere (HTML canonicals, JSON-LD, sitemap.xml, robots.txt, README) if your deployed domain differs.
4. Confirm homepage, /guides/, /tools/, /ads.txt, and /sitemap.xml.
5. Add the real domain to the matching AdSense account, then submit sitemap via Search Console.
